# 校园助手 交接文档

面向接手开发的 AI / 人类工程师。读完本文应能独立完成：本地开发、自检、构建、打包 exe、更新 U 盘副本，并避开已知的坑。

最后更新：2026-11-21（版本 0.2.0）

---

## 1. 项目是什么

「校园助手」是基于 DeepSeek API 的桌面聊天应用，面向学校触屏一体机与教师个人电脑使用。

- 前端：React 18 + TypeScript + rspack + CSS Modules + zustand
- 接口：DeepSeek Anthropic 兼容 Messages API（`/anthropic/v1/messages`），流式 SSE
- 交付：单文件 Windows exe（内置前端资源）+ 网页版本地服务两种形态
- 语言：界面中/英双语，默认中文
- 设计：瑞士极简，纯色、1px 边框、无渐变/阴影/模糊；默认浅色主题

当前主线功能：聊天、深度思考、联网搜索、图片多模态（自动 OCR 双通道）、相机拍照、快捷卡片、文档分屏放映、表格标记提取并生成放映名单、语音输入/朗读、会话历史导入导出、错误诊断。

## 4. 开发、构建、发布

### 4.1 本地开发

```powershell
cd campus-src
pnpm install
pnpm dev          # rspack dev server，端口 8090
```

开发模式下 `__API_ORIGIN__` 为空，接口同源；需要直接连官方 API 时设置 `CAMPUS_API_ORIGIN`。

### 4.2 自检（提交前必跑）

```powershell
cd campus-src
pnpm type         # tsc 类型检查
pnpm lint         # oxlint
pnpm test         # vitest，当前 17 个用例
pnpm check        # 以上三项串联
```

### 4.3 生产构建

```powershell
cd campus-src
pnpm build        # 内部执行 scripts/build.mjs，跨平台可用
```

等价于 `NODE_ENV=production rspack build -c rspack.config.ts`。构建会注入 `__APP_VERSION__`、`__BUILD_TIME__`，并把 `index.html` 图标缓存参数替换为 `?v=<version>`。

### 4.4 一键发布（推荐）

```powershell
# 只构建前端并同步 campus-edition
node scripts/release.mjs

# 构建 + 打包 exe
node scripts/release.mjs --exe

# 构建 + 打包 + 同步 U 盘
node scripts/release.mjs --exe --usb D:\校园助手
```

脚本行为：

1. 在 `campus-src` 执行生产构建
2. 同步 `dist` 到 `campus-edition`，写入 `version.json`
3. 可选打包 exe（默认**不嵌入** API Key）
4. 可选同步到 U 盘：exe 放根目录，网页版放 `campus-edition\`
5. 生成 `campus-exe/release/manifest.json`（版本、构建时间、exe SHA256、首页哈希）

U 盘同步不会覆盖已有的 `config.json`。

### 4.5 只同步网页版目录

```powershell
$d = "C:\path\to\chat-demo\campus-src\dist"
$e = "C:\path\to\chat-demo\campus-edition"
robocopy "$d\static" "$e\static" /MIR /NFL /NDL /NJH /NJS
Copy-Item "$d\index.html","$d\favicon.ico","$d\favicon.svg","$d\apple-touch-icon.png" $e -Force
```

`robocopy` 退出码 0–7 都算正常。

### 4.6 重新生成图标（改了 logo 才需要）

```powershell
powershell -ExecutionPolicy Bypass -File campus-exe\make-ico.ps1
```

- 16/20/24/32/40/48px 取自 `assets/logo-small.svg`
- 64/96/128/256px 取自 `assets/logo.svg`
- 同时生成 `assets/favicon.ico`、`assets/apple-touch-icon.png`、`campus-exe/icon.ico`、`campus-exe/icon-source.png`
- apple-touch-icon 背景为白色
- 依赖 Edge 无头渲染；受限环境可能返回非 0，但 PNG 已生成，以文件是否存在为准
- 无需再手改 `index.html` 的 `?v=`，构建会自动使用 package.json 版本号

### 4.7 打包 exe

```powershell
cd campus-exe
node build.mjs
```

产物：`campus-exe\out\校园助手.exe`，约 61 MB。发布时复制到 `campus-exe\release\`。

要点：

- 构建脚本直接读取 `campus-src/dist`
- **默认不嵌入 API Key**（安全默认）。本项目的自用/U 盘发布使用内嵌 Key 版：
  ```powershell
  $env:CAMPUS_EMBED_KEY='1'; node build.mjs
  ```
  会打印警告；分发给他人前请确认密钥可轮换、可吊销。
- 运行版本号来自 `campus-src/package.json`，会写入 exe 文件/产品版本
- 使用 `@yao-pkg/pkg`（node22-win-x64），不是 Node SEA；SEA + postject 在本项目会 0xC0000005 崩溃，已放弃
- 图标/版本用 `resedit`，GUI 子系统补丁偏移 `optionalHeader + 0x44`

### 4.8 更新 U 盘

```powershell
$env:CAMPUS_EMBED_KEY='1'
node scripts/release.mjs --exe --usb D:\校园助手
```

`CAMPUS_EMBED_KEY=1` 才会把 Key 嵌入 exe。不设置时 exe 需要在同目录 `config.json` 提供 `apiKey`（参考 `campus-edition/config.example.json`）。U 盘 `campus-edition\config.json` 含明文 Key，外借前请移除。

## 5. API、配置与服务

- 模型固定 `deepseek-flash`（`src/services/chat/store.ts` 的 `MODEL`），不要改成 Pro
- 前端不保存、不要求用户输入 API Key；旧版 localStorage 中的 key 会在 `settings.ts` 启动时清除
- 接口前缀：`${API_ORIGIN}/anthropic/v1`；Files API 需带 `files-api-2025-04-14` beta 头
- 本地服务（`serve.mjs` / exe 内置服务）职责：
  - 读取配置并注入 `Authorization: Bearer` 与 `x-api-key`
  - 代理 `/models`、`/anthropic/*`、`/v1/*`
  - 静态白名单（`/`、`/index.html`、`/static/*`、favicon 等），带路径穿越防护
  - 安全响应头：`nosniff`、`Referrer-Policy`、`X-Frame-Options`、CSP（`img-src` 允许远程 https/http 图片）
  - 只接受 `127.0.0.1` / `localhost` 的 Host 与同源 Origin
  - `GET /health`：app、version、buildTime、port、uptime、config 状态（不返回 Key）、日志目录
- 配置文件：
  - 网页版：`campus-edition/config.json`
  - exe：同目录 `config.json`，与内置配置合并；解析失败回退内置并在 `/health` 与日志中报告
  - 支持 UTF-8 BOM
  - 环境变量 `DEEPSEEK_API_KEY` / `DEEPSEEK_API_BASE` 可覆盖（网页版）
- exe 端口策略：从 8130 起最多尝试 10 个端口；若被同一应用占用，直接打开已有实例后退出
- 日志：`%LOCALAPPDATA%\CampusAssistant\logs\server.log` / `web.log`，2 MB 滚动

思考强度映射：轻→`output_config.effort=low`，标准→`high`，深度→`max`，「不思考」不发送 `output_config`。继续历史对话时沿用该条消息原来的强度。

OCR：`POST /v1/tools/ocr`，`purpose: rich_layout_recognition`，按页计费。

### 关键产品约定

1. 快捷卡片统一为底部 sheet，所有卡片同款样式；卡片上不显示删除叉，长按约 0.8 秒删除；标题下方保留一句副标题。
2. 文档放映是原文分栏排版，不调用 AI 总结、不改写内容；每条助手消息正文非空时都显示全屏放映入口。
3. 图片多模态为全自动双通道：图片正常上传，同时后台 OCR，识别文本作为不可见 `document` 文本块附加；OCR 失败静默降级，只给轻提示。不做独立“图片 OCR”开关。
4. 表格提取仅由「表格提取」快捷卡片触发，普通拍照/上传不自动进入整理流程；手写内容与图例需纳入识别，结果人工确认后再生成放映稿。
5. 设置里的下拉菜单需浮在遮罩层之上（`body.campus [role='listbox'] { z-index: 1600 }`）。
6. Logo 使用网友绘制的「大肥鱼」头像（蓝发鲸鱼娘），素材来自 `zhqowo/dsh-whale-tray`；同人二创无明确授权，公开分发需注明来源。`assets/logo.svg` 与 `logo-small.svg` 内嵌 PNG base64，源图见 `logo-fish-source.png`、`logo-fish-icon.png`；旧版 logo 在 `_backup/backup-logo-20261121/`。
7. 诊断信息只记录版本、服务状态、错误堆栈与存储用量，不记录 API Key、对话内容或附件。

## 7. 已知问题与待办

- **API Key 打包策略**：上游默认不嵌入（更安全）。本项目当前的自用发布采用内嵌 Key 版，命令见 4.7 / 4.8；对外分发前务必改用不内嵌版本并轮换 Key。
- 16px 图标辨识度有限（同人插画细节多），如需更清晰可单独为 16–24px 设计简化头像。
- 表格提取暂不支持 Excel 原生单元格样式、多页表格、图片消息上的「整理表格」入口。
- `docs/发布与运维.md` 与 README 由上一轮接手者新增，若流程再变需同步更新。

## 8. 常见坑

1. 旧实例占用端口：新版 exe 会自动换端口（8130–8139），若检测到同一应用会直接打开已有窗口。若界面仍是旧版，先结束所有 `校园助手` 进程。
2. `config.json` 带 BOM 会导致 JSON 解析失败；服务端已做 `replace(/^\uFEFF/, '')`，手写配置也请存为无 BOM UTF-8。
3. 不要用 `rm -rf` 写进 npm scripts；已改为 `campus-src/scripts/build.mjs`。
4. 删除 U 盘深层目录时 PowerShell `Remove-Item` 可能报“目录不为空”或 NullReference；用 .NET 接口：`[System.IO.Directory]::Delete($path, $true)`。
5. 改了 logo 一定要重跑 `make-ico.ps1` 并重新构建，图标缓存参数会自动跟随版本号。
6. 直接改压缩后的产物无法维护；所有改动应在 `campus-src/src` 内完成再重新构建。
7. CSP 若再收紧，注意搜索结果站点的远程图标；当前 `img-src` 已允许 https/http 图片。

## 9. 接手后的验证清单

1. `cd campus-src; pnpm check` 全绿（类型、lint、17 个测试）
2. `node scripts/release.mjs` 成功，`campus-edition/version.json` 为 0.2.0
3. 启动网页版，侧边栏显示大肥鱼头像，标题「校园助手」
4. 设置 → 诊断：能看到版本、服务状态、配置状态、存储用量
5. 发一条消息确认流式回复；上传图片确认 OCR 双通道；用表格提取卡片生成一次放映稿
6. `node scripts/release.mjs --exe` 生成 exe，图标为鲸鱼娘；当前自用版内嵌 Key，双击即可对话。如需验证无 Key 行为，构建时不设 `CAMPUS_EMBED_KEY`。
