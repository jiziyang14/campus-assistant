# 跨设备同步聊天记录

当前采用手动导入导出，不依赖服务器。核心目标是：**两台电脑来回导入时，不覆盖、不串台。**

## 使用步骤

1. 在原电脑：设置 → 数据管理 → 导出全部，得到一个 `deepseek_data-日期.zip`
2. 把 ZIP 拷到另一台电脑（U 盘、网盘均可）
3. 在新电脑：设置 → 数据管理 → 上传，选择这个 ZIP
4. 在确认弹窗里选择 **合并导入（推荐）**

## 合并导入的规则

- 保留本机现有会话，只追加归档里的会话
- 会话 ID 相同且内容一致（更新时间、消息数都相同）：视为重复，跳过
- 会话 ID 相同但内容不同（两台电脑各自改过同一个会话）：
  - 不覆盖任何一方
  - 新导入的那份另存为「标题（导入）」，两条都保留
- 归档里的附件会全部换成本地新的文件 ID，避免两边图片互相串台
- 内容完全相同的附件不会重复占用空间（同一份归档内去重）

## 覆盖导入

只有一种情况用覆盖导入：**本机数据损坏，要从备份完整恢复**。它会先清空本机会话和附件，再写入归档，不能与合并混用。

## 建议的工作流

- 每次换电脑前先导出一次，作为最新快照
- 到另一台电脑后先合并导入，再开始新对话
- 不要在两台电脑上同时修改同一个会话后再反复合并，否则会产生多个「（导入）」副本
- 定期清理不再需要的副本会话

## 限制

- 没有自动同步，也没有账号体系；靠手动搬运 ZIP
- 同一时间只应在一台电脑上产生新记录，避免频繁冲突
- 远端 Files API 上的旧附件不会自动删除，长期使用需留意配额
